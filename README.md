# 🧉 Nativo Mates https://nativomates.github.io/NativoMates/index.html

> Sitio web desarrollado como proyecto académico para la implementación de una landing page de productos, con foco en experiencia de usuario, interacción y medición mediante Google Analytics 4 y Google Tag Manager.

---

## 📌 Descripción

**Nativo Mates** es un proyecto web desarrollado en el marco de una materia universitaria, pensado como una representación funcional de una tienda online de productos relacionados con el mate.

El sitio permite al usuario navegar por diferentes secciones, visualizar productos, consultar información y acceder a canales de contacto para realizar consultas o potenciales compras.

A diferencia de un e-commerce tradicional, el proyecto **no utiliza una base de datos ni un sistema de gestión de productos, usuarios o pedidos**. Los productos y contenidos se encuentran definidos directamente en los archivos del proyecto.

El principal objetivo del proyecto es demostrar la implementación de una experiencia web funcional y, especialmente, analizar el comportamiento de los usuarios dentro del sitio mediante herramientas de analítica digital.

---

## 🎯 Objetivos del proyecto

- Desarrollar una landing page funcional y responsive.
- Crear una experiencia de navegación orientada a la presentación de productos.
- Implementar diferentes secciones y páginas dentro del sitio.
- Incorporar interacción mediante JavaScript.
- Implementar **Google Tag Manager (GTM)**.
- Implementar **Google Analytics 4 (GA4)**.
- Registrar y analizar interacciones relevantes de los usuarios.
- Comprender el comportamiento de los visitantes dentro del sitio.
- Aplicar conceptos de analítica web y medición digital.

---

## 📊 Analítica y medición

Uno de los principales componentes del proyecto es la medición del comportamiento de los usuarios.

### Google Tag Manager

Se utiliza **Google Tag Manager** como sistema de gestión de etiquetas para detectar y enviar diferentes interacciones realizadas dentro del sitio.

Entre las interacciones contempladas se encuentran:

- Clicks en botones.
- Interacciones con botones de contacto.
- Clicks hacia WhatsApp.
- Interacciones con diferentes llamados a la acción (CTA).
- Navegación e interacción con distintas secciones.

GTM permite centralizar la configuración de los eventos sin necesidad de modificar constantemente el código fuente del sitio.

### Google Analytics 4

Los eventos registrados mediante Google Tag Manager son enviados a **Google Analytics 4**, permitiendo analizar métricas relacionadas con el comportamiento de los usuarios.

Algunos de los datos que pueden analizarse incluyen:

- Usuarios.
- Sesiones.
- Páginas visitadas.
- Tiempo de interacción.
- Eventos.
- Interacciones con botones.
- Clicks en WhatsApp.
- Rendimiento de las diferentes páginas.

El objetivo es utilizar estos datos para comprender qué elementos del sitio generan mayor interacción.
